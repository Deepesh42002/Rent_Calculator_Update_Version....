Expense Split Calculator

A simple Python program that adds rent, food, and electricity costs, then divides the total bill between people.

## Features

- Calculates the electricity cost from units used and the price per unit.
- Splits the total bill between the people sharing the expenses.
- Shows the currency symbol and number format for India or the United States.
- Checks that the number of people is greater than zero.

## Supported country inputs

- India: `INDIA` (shows `₹` and Indian comma formatting)
- United States: `UNITED STATES`, `US`, `USD`, or `USA` (shows `$` and US comma formatting)

Inputs are not case-sensitive. For example, `usa` and `USA` both work.

## Run the program

Make sure Python 3 is installed. In a terminal, run:

```bash
python Calculator_Update_Version.py
```

Enter the country, rent, food cost, electricity units, charge per unit, and number of people when asked.
